Hangman Game – Python Programming Internship

Project Overview

The Hangman Game is a beginner-friendly word-guessing game developed using Python.

The computer randomly selects a secret word, and the player tries to guess it one letter at a time before running out of attempts.

Technologies Used

- Python 3
- Python IDLE
- Random module

Features

1. Random word selection
2. Three difficulty levels: Easy, Medium and Hard
3. Hint system
4. Limited guessing attempts
5. Input validation
6. Score tracking
7. Replay option
8. Final score display

How to Run the Project

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Open "hangman_final.py" using Python IDLE.
5. Press F5 to run the game.
6. Select a difficulty level and start guessing!

Alternatively, run the program using the terminal:

python hangman_final.py

Game Instructions

- Choose a difficulty level.
- Guess one letter at a time.
- Type "hint" to receive a clue.
- Only one hint is allowed per round.
- Correct guesses reveal letters.
- Incorrect guesses reduce your remaining attempts.
- Win the game to earn points.
- Choose whether to play another round.

Scoring System

Difficulty| Winning points
Easy| 10
Medium| 20
Hard| 30

Using a hint reduces the winning score by 5 points.
